关于

这是一个由个人需求出发的小项目。

我是一名博士生，日常研究中需要持续跟踪最新发表的期刊论文。最开始，我使用期刊和数据库提供的邮件 Alert 来获取更新，但很快发现两个问题：一是我并没有养成每天检查邮件的习惯；二是传统 Alert 往往只能按照期刊、主题等较宽泛的条件订阅，很难真正做到按照自己关心的关键词进行精准筛选和推送。

后来，随着 AI Agent 的发展，我开始尝试用 Agent + Mail 的方式，让 Agent 每天自动进入邮箱筛选期刊alert。它确实解决了“自动化”的问题，但也带来了新的成本和限制：如果每天都需要 Agent 主动执行检索、判断和推送，就会持续消耗 Token；同时，这套流程依赖本地电脑运行，只有电脑开机时才能完成推送。一旦电脑没有打开，自动化也就随之中断，而且在手机等其他设备上也无法方便地查看结果。

于是我开始想：有没有一种不需要每天调用 AI、不依赖某一台设备，也可以自动完成文献监测的方法？

最终，我选择了另一条思路——直接读取论文 Alert 邮件，对邮件中的文献信息进行自动整理、关键词匹配和筛选，再把真正相关的内容呈现出来。

这样既保留了期刊和数据库 Alert 本身稳定、及时的信息来源，又能够在其基础上增加更精细的关键词过滤，同时避免为了完成重复性的日常监测而持续消耗 Token，也不再依赖本地电脑持续开机。

现在，只要能够联网，无论使用电脑、手机还是其他设备，都可以随时查看最新筛选出的文献。

这个项目由此诞生。

项目自 2026 年 8 月 31 日 起持续稳定运行，并在实际使用中不断调整和完善。目前项目已经开源，希望它不仅能解决我自己的文献追踪需求，也能为有类似需求的研究者提供一种简单、低成本、可持续的选择。

它的目标其实很简单：让真正值得关注的新文献，主动来到你面前。

我要定制

用自己的邮箱和关键词，搭建一份专属的文献追踪。

前往 GitHub ↗

  1. 复制项目

    登录 GitHub，打开项目仓库并点击 Fork，将项目复制到自己的账号下。

  2. 订阅论文 Alert

    准备一个专用 Gmail 邮箱，在期刊或数据库中订阅你关注的论文 Alert。目前支持 Elsevier、SAGE、Wiley、Taylor & Francis、Nature、APA PsycAlert 和 Cambridge Core 的提醒模板。

  3. 设置邮箱与筛选规则

    在仓库 Settings → Secrets and variables → Actions 中添加 GMAIL_USERNAME 和 GMAIL_APP_PASSWORD，分别填写邮箱地址和 Gmail 应用专用密码。编辑 config/journals.json：在 ranking.keywords 中设置关键词和权重，正数提高得分、负数降低得分；用 recommendations.minimum_score 和 recommendations.limit 调整推荐门槛与数量。

  4. 启用自动运行与网页

    在自己仓库的 Actions 页面启用工作流，再到 Settings → Pages，将 Source 设为 GitHub Actions。打开 Actions → Update scholarly tracker → Run workflow，完成首次更新。之后每天北京时间 00:00 自动读取昨日邮件并更新网页，电脑和手机都可以访问。

完整配置与运行说明见 项目 README。
